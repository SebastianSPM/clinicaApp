# || Hackaton 2 || Clinica App 🏥

aplicacion para el manejo de un clinica, ingreso de pacientes nuevos y personal medico, agenda de citas y la posibilidad de ver todo lo anterior desde un menu interactivo en la consola, su funcionamiento es desde el archivo main en donde se mostrara en la consola el  menu de navegacion de al app. Desarrollado el dia 21/08/2026 para la segunda hackaton del programa de desarrollo fullstack junior de generations colombia
